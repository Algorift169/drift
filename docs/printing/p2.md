# Printing arrays in Drift

Drift supports several ways to print values, including arrays and array elements.

## Printing a scalar

```drift
var x = 42
say x
```

## Printing an array element

Use explicit indexing to print a single element:

```drift
var arr[2][2] = {{1,2}{3,4}}
say arr[0][1]
```

## Printing a selection

A selection can be printed directly when it resolves to one value:

```drift
var arr[2][2] = {{1,2}{3,4}}
say arr.select((0,1))
```

## Printing arrays

Bare arrays are not printed directly. The interpreter requires an explicit access such as a single element or a selection, or a declaration that stores the array into a variable with `[]`.

```drift
var arr[2][2] = {{1,2}{3,4}}
var values[] = arr.select((0,1), (1,0))
say values
```

This will print the array contents in a structured form.

## Notes
