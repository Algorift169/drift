# Comment Implementation Technical Deep Dive

## Architecture Overview

The comment system in Drift operates at the **lexer level**, before the parser. This design ensures:
- Comments are completely stripped before parsing begins
- Parser never encounters comment tokens
- Simplified parser logic (no need to handle comments)
- Better error messages (line numbers are accurate)

```
Source Code
    ↓
Lexer (with comment skipping)
    ↓
Token Stream (comments removed)
    ↓
Parser
    ↓
AST / Execution
```

## Lexer State Machine

The lexer tracks comment state using two flags:

### `in_block_comment` Flag
- **0**: Not inside a block comment
- **1**: Currently inside a block comment (`/* ... */`)

### `in_block_comment_code` Flag  
- **0**: Inside a block comment but current line has no code
- **1**: Current line contains executable code in the comment

This allows the REPL to distinguish between:
- Pure comment lines (can continue reading)
- Lines with code in comments (significant for understanding context)

## Comment Skipping Algorithm

### Single-line Comments (`//`)

```c
// In lexer scanning loop:
if (current == '/' && next == '/') {
    skip_until_newline();
    return;
}
```

Steps:
1. Detect `//` sequence
2. Skip all characters until newline
3. Stop at newline (preserve line count)

### Block Comments (`/* ... */`)

```c
if (current == '/' && next == '*') {
    in_block_comment = 1;
    skip_to_end_or_newline();
    if (saw_end_marker) {
        in_block_comment = 0;
    }
}
```

Steps:
1. Detect `/*` sequence
2. Set `in_block_comment = 1`
3. Scan for `*/` sequence
4. When `*/` found, set `in_block_comment = 0`

## String Literal Handling

Critical for correct comment detection - `/*` and `//` inside strings should NOT be treated as comments:

```c
void skip_string_literal(char quote_char) {
    while (current != quote_char) {
        if (current == '\\') {
            skip_next();  // Handle escaped characters
        }
        advance();
    }
}
```

### Example:
```drift
var msg = "This is /* not a comment */"  // This IS a comment
```

The algorithm:
1. Detects opening `"` or `'`
2. Skips all characters including `/*` and `//` until closing quote
3. Handles escape sequences (`\"`, `\\`, etc.)
4. Resumes comment detection after string

## REPL Multi-line Detection

### `is_block_comment_open()` Function

```c
int is_block_comment_open(const char *source) {
    int in_block = 0;
    
    for (each character in source) {
        skip_string_literals();
        skip_single_line_comments();
        
        if (!in_block && sees "/*") {
            in_block = 1;
        }
        if (in_block && sees "*/") {
            in_block = 0;
        }
    }
    
    return in_block;  // True if comment still open
}
```

### REPL Integration

```c
// In run_repl():
while (user_input_continues) {
    if (is_block_comment_open(accumulated_input)) {
        printf("... ");  // Continuation prompt
        read_more_input();
    } else {
        execute_source(accumulated_input);
        printf(">>> ");  // Reset prompt
    }
}
```

## Data Flow Example

### Input Processing:

```drift
var x = 10  // comment
```

**Lexer Processing:**
1. Read `var` → create TOKEN_VAR
2. Read `x` → create TOKEN_IDENTIFIER("x")
3. Read `=` → create TOKEN_EQUAL
4. Read `10` → create TOKEN_INTEGER("10")
5. Read `//` → enter comment skip mode
6. Skip until newline → return 0 tokens
7. Read newline → create TOKEN_NEWLINE
8. EOF → create TOKEN_EOF

**Token Stream Output:**
```
[TOKEN_VAR, TOKEN_IDENTIFIER("x"), TOKEN_EQUAL, TOKEN_INTEGER("10"), TOKEN_NEWLINE, TOKEN_EOF]
```

Notice: No comment tokens in the output!

## Performance Considerations

### Time Complexity
- Single pass through source: **O(n)** where n = source length
- String literal detection: Integrated into main loop
- Comment detection: Single character lookahead

### Space Complexity
- Two boolean flags: **O(1)**
- No buffering of comment text
- Comments discarded immediately after processing

### Optimization: Early Termination
For REPL's `is_block_comment_open()`:
- Stop scanning if sufficient data exists to determine state
- No need to process entire input if determination is clear

## Error Handling

### Unterminated Block Comments

```drift
var x = 10  /* This comment never closes
say x       <- This line is ignored by lexer
```

The lexer handles this gracefully:
1. Sets `in_block_comment = 1` at `/*`
2. Never finds `*/`
3. Reaches EOF while still in comment
4. All subsequent tokens are suppressed

The REPL detects this and shows continuation prompt:
```
>>> var x = 10  /* This comment never closes
... say x
... */
>>>
```

### Nested Comment Delimiters

```drift
/* Outer comment
   /* Inner delimiter - just treated as text, not a nested comment */
   Still in outer comment
*/
```

The implementation treats `/*` inside a comment as regular text, not as a new comment start. This is standard behavior in C-style comments.

## Integration Points

### In Lexer (`lexer/lexer.c`)

```c
Token *lexer_scan_all(Lexer *lexer, size_t *token_count) {
    while (lexer->index < lexer->length) {
        // Skip comments first
        if (lexer_skip_comments(lexer)) {
            continue;  // Comment was skipped, try next char
        }
        
        // Normal token scanning
        Token token = scan_next_token(lexer);
        // ... add to token array
    }
}
```

### In Main REPL (`main.c`)

```c
void run_repl(void) {
    while (fgets(line, sizeof(line), stdin)) {
        // Accumulate input
        
        // Check for open comments
        if (is_block_comment_open(accumulated_input)) {
            printf("... ");  // Wait for more input
        } else {
            // Execute and reset
            execute_source(accumulated_input);
            printf(">>> ");
        }
    }
}
```

## Debugging Comments

To debug comment processing:

1. Add logging to `lexer_skip_comments()`:
   ```c
   if (debug_mode) {
       fprintf(stderr, "Skipping comment at index %zu\n", lexer->index);
   }
   ```

2. Trace REPL state:
   ```c
   fprintf(stderr, "Block comment open: %d\n", is_block_comment_open(input));
   ```

3. Print token stream to verify comments removed:
   ```c
   for (each token in stream) {
       printf("Token: %s\n", token_type_name(token));
   }
   ```


The comment module is compiled as part of the standard build process with no special flags required.
