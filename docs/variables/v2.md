# Variables and arrays in Drift

Drift variables can hold scalars, arrays, or values produced by array access expressions.

## Array declarations

Arrays are declared with square brackets after the variable name:

```drift
var arr[2][2][2] = {{1,2}{3,4}}{{5,6}{7,8}}
```

The bracket list declares the rank of the array. Each dimension is fixed at declaration time.

## Array initialization

Both fixed-size and dynamic arrays can be initialized from literals.

- Fixed-size arrays use the bracketed dimensions and nested initializer blocks.
- Dynamic arrays can be created from a selection expression such as `arr.select(...)` when the declaration explicitly expects an array value with `[]`.

## Selection semantics

A `select()` expression reads one or more elements from an array. When the declaration is a scalar variable, a selection must return exactly one value.

```drift
var value = arr.select((0,1,1))
```

If a selection returns multiple values, the declaration must explicitly request an array result:

```drift
var values[] = arr.select((0,1,1), (0,1,2))
```
